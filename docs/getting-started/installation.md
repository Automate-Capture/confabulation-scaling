# Installation

## From PyPI

```bash
pip install confabulation-scaling
```

## From Source

```bash
git clone https://github.com/Lumi-node/confabulation-scaling.git
cd confabulation-scaling
pip install -e ".[dev]"
```

## Requirements

- Python >= 3.10
- Dependencies: Levenshtein, __future__, confabulation_scaling, gzip, numpy, requests, scipy
